Backup & Restore

A complete backup packages a validated Standard Library and the exact Raw Storage value. The two sections can be restored independently.

Complete Backup

Each backup includes a format version, creation time, record count, and SHA-256 integrity checks for its data sections.

  • Standard Library: validated entries for normal restoration.
  • Raw Storage: exact browser-stored value, including unreadable or malformed data.

Standard Library replaces the current Grimoire library. Raw Storage writes the exact saved value and may return the app to recovery mode if that value is damaged.

Compatibility & Safety

  • Backup format version is independent of the app version.
  • Older supported formats are identified and migrated without modifying the source backup.
  • Unknown newer formats are rejected safely.
  • Restores create and verify a pre-restore safety snapshot.
  • Restored data is read back and validated; failed writes are rolled back.
  • No sample entries are substituted when stored data cannot be read.

This release supports the current complete-backup format and the legacy raw-recovery wrapper and plain JSON library-array formats.
